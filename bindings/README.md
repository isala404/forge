# Forge language bindings

This directory contains Forge's three non-Rust language packages. Rust lives at the repository root. JavaScript supports both Node.js and Bun from the same npm package.

Package names:

- Rust: `forgelib` on crates.io
- Node.js: `forgelib` on npm
- Python: `forgelib` on PyPI
- Go: `github.com/isala404/forge/bindings/go`

The coordinated release targets are:

- crates.io: `forgelib`
- npm: `forgelib`
- PyPI: `forgelib`
- Go module: `github.com/isala404/forge/bindings/go`
